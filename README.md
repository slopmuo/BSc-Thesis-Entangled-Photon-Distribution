# Entangled Photon Distribution - Data Analysis

This repository contains the data acquisition and processing notebooks used for the analysis and experimental characterization of an entangled photon pair distribution system. This work was developed for my Bachelor's Thesis in Engineering Physics at the Czech Technical University (CTU) in Prague.

## Functionality
The code processes raw experimental data to evaluate quantum entanglement fidelity and temporal correlations. Key functionalities include:
* **Coincidence Logic:** Processing time-tagged events and histograms from SPAD detectors.
* **Quantum State Tomography (QST):** Reconstructing density matrices from experimental correlation data.
* **Signal Analysis:** Analyzing PMD (Polarization Mode Dispersion) evolution and OTDR data for inter-laboratory fiber distribution.
